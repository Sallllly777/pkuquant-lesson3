# Level-2 初步清洗与因子研究

本模块针对本项目的 `20260923` 单日数据，复用交易系统的逐笔订单簿语义。原始 ZIP 只读；派生数据、结果和图表分别写入 `data/cleaned/20260923/`、`reports/factor_research_20260923/`。它输出预测诊断，不输出策略收益回测。

## 运行

在项目根目录 `E:\pku-quant-3` 的 PowerShell 中执行，使用已安装依赖的 Python：

```powershell
cd E:\pku-quant-3
python -m pip install -r requirements-research.txt
python -B -m research.pipeline all
```

这台机器已验证可用的解释器是：

```powershell
& 'C:\Users\Lenovo\AppData\Local\Programs\Python\Python312\python.exe' -B -m research.pipeline all
```

分阶段运行：

```powershell
python -B -m research.pipeline clean
python -B -m research.pipeline features
python -B -m research.pipeline analyze
python -B -m unittest discover -s tests -v
```

`features` 会先重新清洗再重建；`analyze` 使用已保存面板重新生成统计、图表及中文报告。再次运行会覆盖同名派生文件。读取 ZIP 和排序需要数GB可用内存；清洗版本和面板合计约256MiB。模块锁定该交易日，其他日期必须先检查供应商数据口径再扩展，不能只改文件名。

只有交易模拟器所需依赖时，原21项测试照常运行，研究测试会明确跳过；安装研究依赖后运行完整42项测试。

## 输出

第三轮目标建模与最终报告（需要先生成下面的第二轮 `scored_panel.parquet`）：

```powershell
python -B -m research.final_study all
python -B -m research.final_report
```

输出在 `reports/final_research_20260923/`，阅读 `最终因子研究报告.md` 或内嵌图表的 `最终因子研究报告.html`。21,500个独立任务覆盖上午与下午，保存88,069条仍未完成的订单状态。训练09:35—10:50前、隔离5分钟、留后10:55—11:25前、午后13:05—14:50前复核；此交易日已在前轮被观察，不是真正未见日期测试。

三个预测目标为30秒方向价格变化、任务截止前余量完全成交概率、条件于后续有成交的成交后30秒中间价变化。新挂单与存续挂单分别训练；状态等权，不使用依赖未来成交时间的“每个任务总观察次数倒数”权重。模型特征由白名单指定，不使用旧组合分数、标签或未来报价。逻辑回归L2=0.01、岭回归L2=0.1固定；所有缺失填充及尺度只用训练段。

共有9组模型和11种规则，包括市场状态／方向／排队输入对照，以及价格择时、成交筛选、风险筛选、三目标组合和0／1／5秒撤单延迟。撤单规则只使用当时已观测状态，截断固定参考行情中的模拟成交路径；撤单后不重挂，余量在原30秒截止按报价估值。延迟期间新增部分成交会使估值数量与触发时记录的深度均价数量不同，存在小订单深度近似；部分余量再申报量无效另行标记。

仅重新拟合与计算统计用 `python -B -m research.final_study analyze`。全部结果、参数、输入对照、逐任务策略选择及分股票／时间块统计均保留。该报告明确披露风险预测和简单撤单规则的失败结果，不把相对执行价格改善称为策略利润。

组合使用上午逐股均值/标准差，特征裁剪到正负5个标准差，固定岭回归正则项0.001。下午已在第一轮被观察，因此不是全新样本外验证。目标是逐股标准化的30秒中间价变化；组合分数是相对上午常态的信号，不直接等于基点预测值。

执行实验在原回放引擎上加入快速盘口和参考报价轨迹，匹配语义不变。每个任务重置实验资金和旧底仓；每只股票每分钟各一笔买入和卖出，主板100股、科创板200股。报单保持信号时刻最优本方报价，延迟到达时可能已成为可立即成交的限价单；从实际到达时起等30秒再即时撤单。没有模拟撤单通信延迟。

截止未成交量按当时可见对手盘估值，未实际重新申报。部分成交剩余量不一定满足最低申报量，另存有效性标记。所有报价估值、成交后中间价变化和相对成本改善都不是可兑现的组合收益；买卖任务均衡的实验设计也不代表真实发单分布。

## 清洗约定

检查空值、非有限数、时钟格式、事件代码、价格股数、重复键。逐笔业务键为 `(Channel, BizIndex)`，快照观测键为 `(Symbol, Time)`。仅删除完全一致的重复记录；逐笔冲突或非法记录进入隔离文件并停止后续重建，不靠猜测补齐。不同内容但同一名义时刻的快照保留并标记。

原始价格为float32，新增以整数分存储的报价字段；超过0.1分的舍入偏差会隔离。没有统一删除零值，没有缩尾，也没有用当天后面的数据填前面的缺口。原有字段不覆盖。订单状态、竞价、连续竞价、盘后机制分别处理。

委托A事件是挂入订单簿的剩余量，不应当作完整母单初始量。先成交后披露余量的主动订单是正常现象。盘口重建按逐笔业务序号处理；原快照有名义时间偏差，不用于因子输入或未来中间价标签。

## 字段与公式

价格内部为分，数量为股；收益、报价偏差、波动均为基点，1bp=0.01%。`time_ms` 是当日零点以来毫秒，时区沿用数据的中国交易时间。`session` 为AM/PM。

令 `b,a` 为买一卖一，`B_i,A_i` 为对应第i档挂单量，`m=(a+b)/2`。

| 字段 | 定义 |
|---|---|
| `obi1/obi5/obi10` | 前N档 `(sum(B)-sum(A))/(sum(B)+sum(A))` |
| `weighted_obi` | 同上，前十档每档按 `1/i` 加权 |
| `weighted_mid_bias` | `((a*B_1+b*A_1)/(B_1+A_1)-m)/m*10000`；静态加权中点 |
| `ladder_gap_bias` | `(卖十到卖一距离−买一到买十距离)/m*10000`；不足十档用可见最远档 |
| `concentration_bias` | `B_1/sum(B_1..10)-A_1/sum(A_1..10)` |
| `trade_imb_5/30/60` | 过去对应秒数内主动买卖成交量差除以总量 |
| `trade_count_imb` | 过去30秒主动买卖成交笔数差除以总笔数 |
| `large_trade_imb` | 过去30秒、单笔金额不少于10万元的主动买卖量不平衡；不是母单规模 |
| `new_order_imb` | 过去30秒新增剩余买单量与卖单量的不平衡 |
| `cancel_pressure` | 过去30秒 `(卖撤单量−买撤单量)/总撤单量` |
| `fast_cancel_pressure` | 同上，但仅统计已知挂入后1秒内撤销的剩余量 |
| `net_resting_flow` | `(新增买−新增卖+撤卖−撤买)/(全部新增量+全部撤单量)` |
| `ofi_5/30/60` | 最优买卖档事件流量不平衡累加，除以观察时刻买一卖一总量 |
| `momentum_5/30/60` | `log(m_t/m_(t-w))*10000`；不跨午休 |
| `vwap_gap` | `(m_t−过去30秒成交均价)/m_t*10000`；无成交时缺失 |
| `peer_momentum_30` | 其余样本股票过去30秒动量的等权平均；不是官方指数 |
| `relative_momentum_30` | 自身过去30秒动量减上述其余股票均值 |
| `spread_bps` | `(a-b)/m*10000` |
| `log_depth10` | 买卖前十档总量的 `log(1+quantity)` |
| `event_rate` | 过去30秒逐笔事件数除以30 |
| `realized_vol_60` | 过去12个5秒中间价对数变化的平方和开根号乘10000 |
| `mean_trade_value` | 过去30秒总成交金额（元）除以成交笔数 |
| `cancel_share` | 过去30秒撤单量除以新增和撤单量之和 |
| `quote_age_ms` | 最优买卖价或量距离上次改变的毫秒数 |

无事件的量不平衡取0；无成交的VWAP/均笔金额保留缺失。`raw_*_5/30/60` 保留对应窗口中间统计，`raw_notional_cent_*` 单位为“分×股”。不平衡分母为0时取0，模型可以另加无成交/无新增事件指示变量。

OFI对相邻状态0、1的单次贡献为：

```text
I(b1>=b0)*B1 - I(b1<=b0)*B0
- I(a1<=a0)*A1 + I(a1>=a0)*A0
```

只在双边报价存在时计算。滚动窗口为 `(t-w,t]`，所有同毫秒事件先完成，再采样；不会把下一秒事件装进当前窗口。

## 标签与评价

`ret_hs=log(m_(t+h)/m_t)*10000`，h为1、5、10、30、60、120、300秒，另存31/35秒以检验延迟。未来报价用逐笔流的as-of状态，不能跳过无效状态去借旧价格。标签碰到阶段边界则缺失，不跨午休或14:57后的集合竞价。

`bid_fwd_*`、`ask_fwd_*`、`ret_*`、`delayed_*` 都是**未来标签，不得作为因子输入**。面板里也有价格、时间、原始统计；默认训练只选 `factor_registry.json` 白名单里的字段，不自动选择全部数值列。

上午09:35—11:25前用于选择因子方向及逐股20%/80%阈值，下午13:05—14:50前同日复核。主排名为30秒逐股Spearman IC等权均值绝对值，取前8名。全部25个候选的7个窗口均公开，避免只披露最优项。

同时报告逐股方向一致比例、横截面IC、5分钟时间块、减少标签重叠的稀疏抽样、上午定义的宽/窄价差分组、板块分组、因子相关及延迟敏感性。累计窗口相关不能当作信号半衰期；稀疏抽样也没有消除跨股和跨时段依赖。

报价标记变化仅是成本诊断，不是有资金、可卖底仓、排队与交割约束的收益。没有从单日推断年化收益或宣称统计显著。研究出处、具体数值和后续假设在生成的中文报告中。
